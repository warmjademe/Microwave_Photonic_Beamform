# Dataset and source cleanup — 31 October 2026

The cleanup preserves the current paper's data splits, trained models, controls, raw reception metrics, statistical analyses and source snapshots. The release manifest and its per-file indices are unchanged.

## Removed material

| Category | Action |
|---|---|
| Duplicate release packaging | Removed local archives and split upload parts after matching their hashes to the published release manifest |
| Download verification copies | Removed temporary downloaded parts after their integrity checks |
| Superseded cleanup archives | Removed old local compressed cleanup copies |
| Process management | Removed 15 obsolete, unreferenced queue/temporary-dispatch scripts; retained the direct numerical entry points |
| Unrelated project folders | Removed the root `archives`, `literature_2025_BLoS_AI`, and `literature_deep_learning_baselines_20260924` folders after checking current manuscript and source dependencies |

Dataset duplicate files occupied **8,857,652,862 bytes**. The three unrelated root folders occupied **1,190,645,619 bytes**. These are file-size totals, not a measurement of filesystem free-space change.

## Retained material

All **675,079 distinct paths** listed in the ten released data groups remain protected. Current data comprise **3,456 training, 216 validation and 864 test environments**, with all 17 carriers of each environment in one split. The two main evaluation archives, current CRL/CFS ablations, sensitivity and timing records, validation studies and figure sources remain available.

Historical records required to interpret earlier configurations and negative results are retained. Historical correction modules remain frozen-run dependencies, but are not components of the current RLF method. No training, baseline evaluation or dataset generation was started during cleanup.

## Public access

Use [RELEASE_DATA.json](RELEASE_DATA.json) and [the artifact downloader](../source_codes/release_tools/fetch_artifacts.py) for the full data and models. Existing large assets remain on GitHub Releases; deleting local upload copies does not remove those assets. The main branch supplies updated guides and the [portable figure package](../source_codes/Paper_Figures_Generation/README.md), including its input arrays and generated figures.

```bash
python3 source_codes/release_tools/fetch_artifacts.py --list
python3 source_codes/release_tools/fetch_artifacts.py --extract
python3 source_codes/release_tools/fetch_artifacts.py --verify-only
```

The downloader verifies checksums and restores the recorded relative paths. No result values, model weights, dataset memberships or frozen numerical algorithms were changed by this cleanup.
