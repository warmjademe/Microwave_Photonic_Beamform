# 联合频率线性响应基线

目的：检验复响应CNN的收益是否仅来自使用31个频点的联合信息，或来自按相对响应误差训练。原训练协方差估计逐频点计算，其优化目标也不与CNN完全一致。

本基线使用相同864个训练环境、相同公开16探测输入及相同64×31复响应标签。输入为已知两导频平均后的16×31复测量，输出为64×31复响应，再交给完全相同的合法器件控制器。在线接口不接受真实信道或传播参数。

预设三个版本：逐频点相对误差加权线性回归、联合频点相对误差加权线性回归、联合频点未加权线性回归。相对权重为训练目标均方幅度的倒数，仅在拟合时使用。复数岭回归为解析求解，不使用神经网络、验证集或测试调参。相对对角加载固定为训练输入Gram矩阵平均对角线的0.01倍，与原岭估计的相对加载量级一致；不声称该值为全局最优。

所有权重在旧测试公开测量载入前固定。训练及推理在华硕GPU以complex128执行，保存原精度权重和预测；检验线性方程残差、全预测回放、共同相位等变。比较结果属于旧216环境探索阶段，新864确认环境不由此入口加载。
