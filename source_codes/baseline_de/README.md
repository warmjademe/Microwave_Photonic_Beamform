# 有限预算差分进化 DE

入口为 `optimize(session, rng)`。仅依赖 NumPy，使用 `DE/rand/1/bin`：随机选三个不同种群成员，构造 `a+F(b-c)`，再与当前目标进行二项交叉，最后按真实测得质量选择保留者。

默认种群大小 16、变异系数 `F=0.65`、交叉概率 `CR=0.80`。至少一个控制分量强制来自变异向量。所有候选由统一的 `session.project` 限幅、量化；若量化后与目标完全一致，随机改变一个可行控制码，避免无效试探。种群按随机顺序即时更新，没有读取真实信道、真实无噪声分数或其他算法结果。

共同预探测中的不同控制可以直接用于初始种群，因为它们的测量成本已在会话中计入。不足 16 个成员时使用全域随机设置补足，每个新增成员都实际评价并扣预算；不足四个成员时不能执行 `rand/1/bin`，直接返回已测最好设置。低预算可能全部用于初始种群，这应在结果中如实呈现，不能把初始化算成免费步骤。

每个交叉候选使用一次真实反馈。允许测到种群内其他已有点，重新测量照常计费；相等分数也接受候选。全部分数来自静态场景中的带噪反馈，最终质量需独立评价，以免把噪声产生的最大分数当作实际收益。返回控制一定已经测量过。

这是对 DE 的有限种群、离散有界硬件控制适配。种群大小不是通常按维数成倍扩展的配置，也未调用 SciPy 实现，不声称全局最优；比较时报告全部实际评价次数、运行时间和固定随机种子。
