# SPSA 双边同时扰动适配版

入口为 `optimize(session, rng)`；控制、预算与量化由共同会话定义。算法只能查看预探测和自身测量，不能查看真实信道。

每步同时给 128 项控制加入随机正负扰动，分别测量两次质量，计算每个控制方向的差分近似，再形成上升更新。默认扰动幅度 `0.08/(k+1)^0.101`，更新步长 `0.20/(k+1)^0.602`，其中 `k` 从零开始。分量梯度统一除以 `max(1, 最大绝对分量)`，限制一次更新的幅度。

为避免量化吞掉扰动，扰动先转换为至少一个整数控制码；为避免边界单侧裁剪引入错误差分，将本步中心移入可进行等幅双边扰动的位置。使用 300/24 个码间隔时，两侧控制均精确落在合法网格。中心移入操作不消耗反馈，也不会被误记为已测量结果。

正负扰动各消耗一次反馈；更新点如果尚未查询且预算足够，也消耗一次反馈，因此一般每步最多三次。已查询的更新点不会被再次评价。正负扰动允许重复测量，按次数完整计费。预算只剩一次时，不计算伪双边梯度，而做一次合法单码邻域试探。最终返回 `session.best_control`，保证实际执行并测量过。

这是有界离散时延/衰减控制的 SPSA 适配，不是连续无约束原算法的逐行复现；边界中心移动、整数扰动、梯度幅度限制和更新点验收都已显式增加。原 SPSA 收敛结论不自动适用于本实现。SPSA 是利用带噪目标反馈的数值优化，此处没有强化学习训练。

算法依据：[Spall 的机构算法说明](https://www.jhuapl.edu/SPSA/Pages/)。最终性能使用独立检验数据，不采用搜索中最高带噪反馈作为无偏性能估计。
