# 多尺度离散坐标搜索

入口：`from baseline_coordinate import optimize`，调用 `optimize(session, rng)`。
仅依赖 NumPy。`rng` 必须是调用方提供的 `numpy.random.Generator`。

输入为已经完成共同预探测的会话。控制向量前 64 项为归一化延时，后 64 项为归一化光衰减，取值均为 `[0,1]`。`delay_levels=300` 表示包含端点的 301 个码，`attenuation_levels=24` 表示 25 个码。物理单位转换、控制限幅和量化由 `session.project` 统一处理。

算法每次只调整一个控制量，利用实际带噪质量反馈选择设置。默认依次使用 `(32,4)`、`(8,2)`、`(1,1)` 个延时码/衰减码的步长。剩余预算在各尺度间分配，避免小预算全部消耗在粗搜索。坐标和正负方向顺序由传入的随机数生成器确定。每个坐标的两侧试探使用相同中心；下一坐标从会话保存的最好已测设置开始。

边界限幅后没有移动的点以及已经查询的控制不再查询；如果所有尺度均无法找到新点，就提前停止。每次真实 `evaluate` 扣一次预算。模型拟合、真信道、无噪声评分均不参与决策。返回值永远是已实际测量的最好控制，而不是尚未执行的建议。

这是针对本项目离散时延/衰减约束的坐标搜索实现，不是原有 `reference_search` 教师：后者可以读取仿真真值，本算法不能。带噪反馈下的“最好观测”可能受噪声影响，最终质量应由共同的独立检验数据评价。默认不对旧点重测，适用于静态控制场景。
