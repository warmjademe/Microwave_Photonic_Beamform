# 最终控制器的软件耗时补充（2026-10-01）

接收质量和最终控制已冻结，本实验只测量实际执行时间，不训练模型、不更改候选、预算或控制结果。覆盖最终网站的 27 个普通控制配置：13 个正式基线在已定义预算下的实现、两个主方法和四个共用消融配置；教师和数字 MRC 不进入同硬件时间比较。64 次主比较单列 13 基线与本文方法。

输入从最终 864 环境的六个功率分组中分别选编号最小的环境，各取全部 17 载频，共 102 条。此规则在计时前固定且不读取接收成绩选样。前置核查固定环境索引 0 的 4/12/20 GHz，覆盖全部 27 配置，不把前置核查当作正式速度结果。计时样本只是全量质量测试的子集。

沿用已冻结模型、在线控制函数和原算法随机流。读取既有 2513 维公开输入；从最终原始记录得到参考控制和已经发生的反馈查询。每次执行仍实际计算网络前向、响应校正、控制搜索与量化，只对序号和全部控制码完全相同的查询返回原反馈标量。查询改变、漏测、最终控制改变都立即失败。严禁控制函数读取预测数组、测试标签或传播真值。

每条输入先热身两次，再计时三次，固定单线程 CPU，网络在华硕 GPU 上执行；这不是新增训练种子。记录每次软件时间、反馈核查回调时间和外层墙钟时间。软件时间排除回调，模型加载不在主指标内。报告平均、中位及第 95 百分位，不用最短一次替代。另按 NativeConfig 的标称测量和切换时间估算总成本，明确不是实体器件实测。

正式运行每个方法前后执行资源门限：GPU 无其他进程、本项目无其他数值进程、CPU 忙碌比例不超过 60%；不终止无关服务、虚拟机或其他任务。CPU 使用固定 5 秒统计窗，保留总 tick、空闲 tick 和实际采样时长；门限失败的快照在退出前保存。前置功能检查采用 0.2 秒窗，不作为速度报告。触发门限保留现场，另建目录重测，不拼接受竞争的时间。此次补充用最终测试的固定子集，取代旧计划中尚未执行的 37 个探索变体速度比较。

2026-10-01 的前两次正式计时因旧 0.2 秒 CPU 瞬时采样超过 60% 停止，保留在 `20261001_final_timing` 和 `20261001_final_timing_run02`。检查发现宿主机的其他 Windows 工作负载使瞬时值波动；独立 5 秒读数为 46.70%。因此在完成任何正式排名前将统计窗固定为 5 秒，阈值保持 60%，不选择多个读数的最小值。新版本重新进行全部前置检查并从头计时，两个旧尝试不计入汇总。

保存固定协议、输入与反馈记录 SHA、实际控制码、逐次时间、资源快照及独立汇总核查。原始质量结果和旧计时预检均保留。

华硕运行：先 `run.py --preflight`，其通过后使用同一源码 `run.py --final --proof <前置检查目录>`。两次输出目录均必须不存在。完成标记只在来源、控制和全部时间统计核验后生成。
