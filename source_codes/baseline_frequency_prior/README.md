# 固定候选先验对照

在新测试结果揭晓前补充这个无需神经网络的对照，检验“质量排序网络是否只是学到总体常用设置”。它只读取同一训练集的四帧平均候选NMSE；不读取测试标签、环境真值或当前接收测量来决定控制。

`global_prior`选择训练集全部环境与频率平均NMSE最小的一个候选，所有输入都用它。`frequency_prior`为4–20 GHz分别选择训练平均NMSE最小的候选，共17个固定设置。平分时使用最小候选索引。两者都从与质量排序网络相同的64套固定候选中选择，输出仍为64路延时及64路衰减。

两者有相同16探测输入可用，但只使用已知载频，实际不需要额外探测；它们不代表利用实时多径信息的自适应方法。选择表由864个训练环境决定，测试216个环境保持留出，不增加网络训练次数。

固定在同一帧5、8次配对APD抽样评分，全部17载频和四个传播因素分组。主要预设比较为`candidate_soft_robust - frequency_prior`；补充报告`complex_response_cnn - frequency_prior`，其中前者与先验共用候选空间，后者使用完整128维控制空间。误码率差按216环境做1000次配对bootstrap，统计种子2026092510。

这个补充对照不修改已经冻结的两条网络流水线；结果不能用于再选择网络轮数、种子或损失。实现为`method.py`，运行与评分入口为`evaluate.py`。
