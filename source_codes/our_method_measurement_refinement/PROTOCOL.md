# 公开测量一致性校正（2026-09-26）

前一轮24训练环境×3载频诊断中，原CNN加MMSE控制的BER为13.8693%，改BER代理为14.0793%；将CNN估计换成真实响应目标、保持MMSE控制，BER为5.2139%。因此暂不采用BER代理替换，下一轮检验估计与实测约束不一致是否有可修正部分。这些数字仅来自训练内定位，不是216环境测试成绩。

## 算法

冻结864环境CNN及其输入，离线仅用同一864训练环境的响应标签拟合预测残差的空间二阶矩。每条残差除以该条CNN预测的RMS幅度，每载频分别汇总64×64矩阵，所有31频点共同估计。它只是一种数据驱动的正则化权重；CNN与公开测量相关，不把该步骤称为独立先验贝叶斯后验或最优无偏估计。

在线已知y（原16次导频合路测量）、A（标称控制的测量矩阵）、R（原公共噪声统计）和CNN输出h。令C为离线残差二阶矩乘当前预测幅度平方，计算：

`h_new = h + C Aᴴ (A C Aᴴ + R)⁻¹ (y − A h)`。

这相当于在保持CNN估计附近的同时，减小与公开导频之间的加权偏差。只使用既有16次测量，不增加反馈；不读取当前环境真值、各路光场或数据符号。真实帧和小信号矩阵存在残差，校正仍可能过拟合噪声，必须用完整接收器检验。

预设两个版本：C使用相同总方差的对角等方差矩阵；C使用训练残差的完整空间二阶矩。两者均无测试调参，强度固定为公式中的1，不扫超参数。控制器保留原MMSE两轮版本。

## 执行与评价

GPU在华硕用冻结模型做训练输入推理，不进行额外神经网络训练，不调整原40轮模型权重。只拟合训练残差统计并保存数据成员、权重、目标、源码哈希。正则化数值加载固定为矩阵迹的1e-12/维数。

先核验零残差不变、公共相位旋转等变、噪声加权测量残差不增、合法控制，以及原控制/接收结果复现。随后只用前一轮预设的24个训练环境及4/12/20 GHz，比较传统估计原控制、CNN原控制、CNN等方差校正、CNN空间校正；复用原缓存CNN以隔离批量推理差异。评价仍为frame5、8次配对噪声，BER主指标，EVM、SER、输出SNR与计算时间作辅助。不同载频不是独立环境。

该筛查不创建验证集、不使用旧测试或新封存测试；只用于决定是否值得在3,456共同成员上重新拟合和做完整机制对照。负结果保留。若机制有收益，还须补齐传统估计/学习估计×无校正/有校正的正式组件比较，不能将本训练筛查当作完成消融。
