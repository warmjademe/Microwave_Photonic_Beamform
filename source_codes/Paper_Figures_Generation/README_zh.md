# 论文分析图生成说明

这个目录负责把**已经完成的实验结果画成论文中的图 3–10**。图 1 是场景示意图，图 2 是方法框架图，它们不是实验数据分析图，因此不在这里重新绘制。

## 最简单的使用方法

进入本目录，依次运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python generate_figures.py
```

生成完毕后打开 [图片总览](generated/index.html)。每张图都有英文、中文两种版本，各自提供 PDF 和 PNG。还可直接打开 [英文八图合集](generated/en/all_analysis_figures.pdf) 或 [中文八图合集](generated/zh/all_analysis_figures.pdf)。

如未找到中文字体，添加 `--zh-font 字体文件的完整路径`；只需要英文图时添加 `--language en`。程序只做已有结果的读取、数值聚合和绘图，不需要 GPU。

## 输入是什么、输出是什么

* `inputs/`：从原实验目录提取的数组和统计文件，共 19 个输入文件。并非抄写论文表格，也不是随机造点。
* `prepare_inputs.py`：把原工程里的绘图输入提取到一个单独目录；通常不用重新执行，现成输入已在这里。
* `generate_figures.py`：先检查输入文件的 SHA-256，再核对指标和计数，最后绘图。每一类图对应一个函数，代码中有中文说明。
* `generated/en/`、`generated/zh/`：各 8 张单独图片，每张包含 PDF 和 PNG；另有一个 8 页 PDF 合集。
* `generated/plot_data/`：图中环境级指标、阵列切面、星座指标的 CSV，方便逐点核对。
* `generated/manifest.json`：程序版本、输入和输出哈希、论文图号与数据来源。

## 八张图分别在做什么

1. **图 3，指标关系**：每个方法有 864 个点。每个点先合并同一个环境的 17 档载频，再计算 BER、EVM 和 SNR。
2. **图 4，载频和功率分组**：展示方法在不同载频、不同接收功率条件下的表现。所有方法使用同一批条件。
3. **图 5，阵列方向图**：按已经固定的阵列间距和延时码，画出真时延与中心频率匹配相移的角度切面；这张图只分析阵列几何。
4. **图 6，最终控制来源**：统计最后选中的是初始设置、模型生成的候选，还是几何码本中的候选。
5. **图 7，星座图**：沿用论文的第 363 个测试环境和 12 GHz 条件。发送符号、噪声、输入和控制全部来自原记录。12 个基线的实际输出相同，因此共用一幅面板；不会人为修改它们的点。
6. **图 8，敏感性**：保留 11 个条件、三种控制方法及配对区间，分别展示总体 BER 和 RLF 相对对照的差值。
7. **图 9，消融**：对比传统估计、CRL、传统估计+CFS、RLF，另列固定扫描。去除 CFS 的配置只有 16 次测量，启用 CFS 为 64 次，图上明确标注。
8. **图 10，训练规模**：对比固定 40 轮与固定 9,200 次参数更新。两条曲线使用相同的 216 个验证环境。

## 为什么不能直接把百分数或 dB 求平均

BER 是总错误比特数除以总比特数。EVM 是先把 NMSE 求平均再开平方。SNR 是先分别累加信号功率与噪声功率，再取它们比值的对数。程序沿用论文的计算方式，并与原统计文件核对，防止画图时换了指标口径。

原始数组里的方法顺序与论文展示顺序不同，程序按保存的方法名对应重排。置信区间直接读取已完成的统计分析，不在绘图时重新抽样。绘图不会覆盖 `latex/` 中的原图，也不会修改任何训练数据或实验结果。
