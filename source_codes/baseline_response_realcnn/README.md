# 实数响应CNN对照

该基线直接检验阶段A的表示方式。它与本项目复响应CNN使用相同864个训练环境、相同16探测公开输入、相同64×31复响应标签、相同相对误差损失，以及同一个器件控制器。

差异是把实部和虚部视为两个普通实数通道，使用三层3D实数卷积和GELU；复数版本使用复数卷积和模长激活。两者都有8×8×31输入网格、三层3×3×3卷积、相同幅度归一化、相同三个公开条件变量和残差输出。实数版本17,524个参数，复数版本17,540个参数。条件层宽度53用于参数量匹配，未用测试结果选择。

固定seed0、40轮、batch64、Adam 0.001、梯度范数上限5，使用最后一轮，无验证集。首次输出层为零，初始输出均为相同岭反演结果。该比较同时改变卷积约束和激活形式，因此用于比较完整实数/复数估计器，不把差异单独归因于某一个算子。

此实验与已有`baseline_cnn`不同：原CNN直接回归128个控制量，本基线估计中间复响应，再用固定物理约束控制算法得到相同的128个器件控制量。原直接控制基线继续保留。
