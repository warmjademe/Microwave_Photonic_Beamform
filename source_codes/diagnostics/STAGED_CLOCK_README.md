# 精确子时刻电输入的数值诊断

本目录新增 `staged_clock.py` 和 `staged_convergence.py`。它们不改动冻结的 `native_sim/native_laser.cpp`，也没有生成替代正式数据集。

原诊断把时间索引统一后仍用线性插值计算 RK4 半步时刻的电输入。高频信号在相邻采样点之间变化较快，插值误差会影响激光响应。新的诊断根据相同的 255 个正频 Fourier 系数构造两倍于积分采样率的电信号，使整步、半步和下一整步都能直接读取连续带限输入的精确采样。固定时长和频格不变，尾端读取周期闭合值，不用最后两个点外推。

速率方程、64 路参数文件、初态求解和步末光场输出沿用原实现。比对符号之前仅按已知的一个积分步末偏移校正时间，不拟合增益或相位。这里的“精确”仅指给定有限 Fourier 系列的子时刻电输入；激光速率方程仍用有限步长的数值积分。

## 已固定的检查

- 首路器件，4/12/20 GHz，两档驱动幅度 0.0002/0.002。
- 积分采样率为原 51.2 GHz 的 1/2/4/8/16 倍，同一连续输入与 2.56 μs 时窗。
- 预先要求最后两级符号相对 L2 差异不超过 1%，再选择相对 16 倍参考最大误差不超过 1% 的最小档。
- 华硕完成 30 次计算。最后两级最大差异 0.001197%；候选 2 倍档最大差异 0.3565%。全部计算均为零误码。

本轮为无传播、无噪声的首路数值诊断。它没有覆盖完整 64 路和合路接收，也不代表与 OSD 离散输出等价。提高积分采样率以后，尚需明确光谱窗口、跨光载波项和接收缓存的一致性；不能直接绕过原光谱支持检查。

## 复现

仅在华硕执行，在远程项目 `source_codes` 目录运行；输出必须使用未存在的新目录：

```sh
../.venv_dl/bin/python diagnostics/staged_convergence.py \
  --root /home/qyb/RESEARCH/wangluqiang_2026_paper_1 \
  --output /home/qyb/RESEARCH/wangluqiang_2026_paper_1/dataset_simulation/diagnostics/staged_convergence_reproduction
```

原始结果位于 `dataset_simulation/diagnostics/20260925_staged_convergence/`，包含预设协议、30 条结果、符号数组、独立编译的 C++ 副本、源码快照与完成摘要。
