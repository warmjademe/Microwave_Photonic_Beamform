# C 补充：同响应监督的实数 CNN

2026-10-30。在读取这项最终测试结果之前固定本协议。

- 复核已有实数响应 CNN 的冻结模型，不重新训练、不选择检查点。实数模型使用 3,456 个训练环境、58,752 条载频记录、seed 0、40 轮、batch 64、Adam 0.001、相对复响应均方损失，参数量 17,524；A 的对应参数量为 17,540。两者共享训练环境、响应标签、初始岭反演、条件变量、尺度处理和离散求解器。
- 复核训练来源、响应数组及权重的哈希。实数模型使用双实通道卷积与 GELU，A 使用受约束的复卷积与模长激活。因此比较的是完整响应估计器，不单独归因于卷积或激活中的一个差异。
- 在既有完整 864 测试环境、17 个载频上评价实数响应直接输出（16 次初始观测）与实数响应加 F（64 次）。使用与原 A/F 相同的输入、噪声、业务帧、测量回调、几何候选顺序及离散求解器。两项均保留，不按结果选择配置。
- 预检使用首个测试环境的 4/12/20 GHz，核对重复推理、合法整数码、候选与直接输出一致、64 次实际去重测量和评分最大值选择；另重新执行 A 与 A+F，逐项对齐原 RQ2 输入、控制、反馈轨迹及接收计数。预检通过且源码身份相同后才能开展全量评价。
- 与已冻结并逐条校验的 A、A+F、固定扫描和传统估计对照组合报告。主要对照为实数响应减 A（16 次）、实数响应+F 减 A+F（64 次），另报 F 的测量成本和相对固定扫描差值。
- 每个指标以环境为单位做 216 层配对 bootstrap，10,000 次、种子 20261030，报告均值差、95% 区间及环境胜/平/负。各指标内对预定四项对照做符号检验和 BH 校正；均值区间与胜负检验回答不同问题。
- 本项补测用于审稿中的监督目标与网络结构问题；既有测试集已被分析，不称为新的未见确认集。没有新增 B、独立干扰源或硬件数据。
- 原数值核心、其他运行任务和历史结果保持不变。全部数值工作在指定远程实验主机执行。原始记录、失败与未通过的检查保留；完成标记只在全部记录、来源和统计核查通过后生成。
