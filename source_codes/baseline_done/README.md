# DONE 思路的时延/衰减控制适配版

入口为 `optimize(session, rng)`，仅依赖 NumPy。使用会话中已经测得的控制和质量反馈，在线拟合控制到质量的关系；没有真实信道访问，没有预先拟合的测试场景模型，也没有强化学习。

代理采用常数项加 64 个随机傅里叶特征：`sqrt(2/64) cos(W u+b)`。`W` 各项为标准差 `4/sqrt(控制维数)` 的高斯随机数，`b` 在 `[0,2π)` 均匀分布。训练目标为全部已测质量的平方残差加 `0.01 ||β||²`。先减去预探测分数均值作为固定偏置，再用递推最小二乘更新系数；固定随机特征在整个会话中不变，常数项同样正则化。

每次构建 24 个全域随机候选、24 个围绕已测最好控制的局部候选及该控制本身。局部扰动尺度轮换 `0.03/0.10/0.25`。代理分数最高的 4 个候选再做 12 步有界投影梯度上升，步长为 `0.08/sqrt(步数)`，梯度最大绝对分量大于 1 时统一归一化。所有这些只是免费的内部代理计算，必须另报运行时间。

下一次实际查询通常选代理预测最好的未测量量化控制；10% 的步骤打乱候选顺序作探索。重复点不再查询，候选池全重复时最多作 32 次随机候选尝试，然后允许提前结束。每个实际测量都经 `session.evaluate` 扣预算，再更新代理。最终返回值始终来自已测量的会话记录，绝不返回未测试的代理最优点。

与原 DONE 的关系：这里保留“随机傅里叶函数近似＋在线回归＋根据代理选择下一次昂贵测量”的思想；固定特征数/正则参数、候选池、投影梯度搜索、离散网格去重及 10% 探索均是本项目明确规定的适配。没有逐行复现原论文的所有探索、优化器、超参数和器件实验配置，也不继承原实验结果或全局收敛结论。应在论文中称为 **DONE 适配版**，而不是原作者代码复现。

经典依据：Bliek 等，*Online Optimization With Costly and Noisy Measurements Using Random Fourier Expansions*，IEEE TNNLS，2018，[大学书目页面](https://research.tue.nl/en/publications/online-optimization-with-costly-and-noisy-measurements-using-rand/)。其光子波束形成应用与当前器件控制对象不同，详见[项目比较设计](../../dataset_simulation/docs/经典基线候选与公平比较设计_20260923.md)。
